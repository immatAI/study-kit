local-first · Windows OCR · approval receipt

Study Kit

Turn image-only PDFs into sanitized, traceable Markdown notes — locally, with no external API.

image PDF
  → extract text + largest image per page
  → Windows.Media.Ocr (local)
  → remove irrelevant pages / sensitive info
  → Markdown
  → approval receipt (source + report + output hashes)

Why

  • Image PDFs often have no text layer; sending them to a cloud model is expensive and leaky.
  • Irrelevant pages and sensitive info should be removed before notes enter a knowledge base.
  • After ingestion, you should know which source, which sanitize report, and who approved it.

What you get

  • extracted.sanitized.md — cleaned Markdown
  • sanitize-report.json — dropped pages and redactions
  • receipt.approved.json + hash chain — verify, tamper detection
  • dedupe — per-page token overlap against existing notes

Demo

The repository ships a synthetic 3-page PDF. No real documents are required.

.\study-kit.ps1 run -Pdf demo\slides.pdf -Out demo\out -DropPages 1
.\study-kit.ps1 approve --dir demo\out --by reviewer
.\study-kit.ps1 verify  --dir demo\out
.\study-kit.ps1 dedupe  --draft demo\out\extracted.sanitized.md --existing demo\existing

Limitations

  • Windows-first; OCR uses Windows.Media.Ocr.
  • Only the largest image per page is OCR'd; OCR may contain typos.
  • Rule-based cleaning is not a guarantee — review high-risk documents manually.
  • Prototype; interfaces may change.
